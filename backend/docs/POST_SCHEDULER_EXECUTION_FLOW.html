Registers cron.schedule('* * * * *'). Includes a critical concurrency guard (isDispatcherRunning) so if a large 1,000-post batch takes 75 seconds, the next minute's ticker skips to prevent overlapping queries!

// backend/src/jobs/cron/postCron.job.js: Line 108
cronScheduledTask = cron.schedule("* * * * *", async () => {
  if (isDispatcherRunning) return; // Concurrency Lock
  isDispatcherRunning = true;
  try { await triggerScheduledPostsNow(); } // Line 117
  finally { isDispatcherRunning = false; }
});

STEP 07 🔀
The Branching Fork: BullMQ Queue Push vs Direct Fallback
jobs/cron/postCron.job.js Lines 61–70

This is the core resilience mechanism you and I decoded! It evaluates whether Redis is alive. If yes, push to queue (Happy Path). If Redis drops or has a timeout, catch the error and execute directly (Fallback Path).
