01Overview & Core Promise

Overview

Most small business owners know they should post on social media consistently, but don't have the time, design skill, or team to do it. BrandFlow removes every step between "I have something to promote" and "it's live, on-brand, on every platform."

Core promise: an SMB owner with zero design knowledge can create and schedule a professional social media post in under 30 seconds.

Problem statement

Small businesses (restaurants, salons, gyms, clinics, jewellery stores, retail, real estate, schools, travel) need a constant stream of festival greetings, offers, and announcements to stay visible — but hiring a designer is expensive, and generic tools like Canva still require design skill and manual publishing across platforms.

02Unified Auth & Role Routing

Single Login & Access Control

There is only ONE single application/web entry point for both End Users and System Admins. Upon login, the platform detects the user's role and routes them accordingly.

ROLE: END_USER

SMB Owner / Manager

Redirects to Brand Kit creation, Single-Choice Dashboard, AI Post Generator, Multi-Platform Scheduler, and Content Vault.

ROLE: ADMIN

System Administrator

Redirects to Admin Management Console: Add Categories, Add Festivals/Days, Upload Base Templates, Add Design Styles, Manage Users.

Server-Side Image Overlay Engine (Node.js Sharp Architecture)

When an end-user selects a template or creates a post, the platform uses Node.js sharp (high-performance C++ libvips library) for ultra-fast, server-side dynamic image composition. This seamlessly places the user's business brand details (logo, name, phone, address, website, offer badges) onto the Admin-uploaded base template.

SHARP ENGINE

1. Multi-Layer Image Composition

Composites base template image buffer + user PNG/SVG logo buffer + dynamic vector SVG text layers (Business Name, Phone, Address, Offer Code, Website) in a single atomic sharp().composite() pipeline.

SHARP ENGINE

2. Precise Coordinate Mapping

Reads layout coordinate metadata defined by Admin (Logo bounding box x, y, w, h, Text Anchor zones, Contact Bar position) to place user assets with pixel-perfect accuracy.

SHARP ENGINE

3. Sub-Millisecond Speed (< 15ms)

Renders customized posters in 5–15ms per image. Uses 90% less memory than Puppeteer/Canvas, scaling effortlessly across concurrent BullMQ background workers for 100,000+ users.

SHARP ENGINE

4. Multi-Format Social Resolution

Outputs pristine 1080x1080 (1:1 Feed Post), 1080x1920 (9:16 Story/Status), and WebP/JPEG formats optimized for social platform API publishing.

13Admin Panel Capabilities

Admin Control Features

Accessible only to users logged in with `ROLE: ADMIN`. Admin configures the master system assets that power all SMB users.

ADMIN POWER

1. Business Category Management

Add, edit, or disable industry categories (Restaurant, Gym, Salon, Medical, Jewellery, Real Estate, School, Travel, etc.) and configure domain image banks.

ADMIN POWER

2. Master Font & Color Palette Library

Add and manage approved Google/Custom Fonts (Space Grotesk, Inter, Playfair, Outfit, Montserrat) and curated Color Palettes/Presets available to SMB users during Brand Kit setup.

ADMIN POWER

3. Festivals & Celebration Days

Add upcoming festivals (Diwali, Holi, Christmas) & national/global celebration days (Independence Day, Women's Day, Environment Day) with target dates and regional tags.

ADMIN POWER

4. Base Template Management & Sharp Coordinate Mapping

Upload master SVG/PNG Base Templates per festival/occasion and configure placeholder coordinate metadata (Logo placement box x, y, w, h, Business Title anchor, Contact Bar, CTA badge). The server-side Sharp Engine automatically overlays each SMB user's Brand Kit details onto these exact coordinates during post generation.

ADMIN POWER

5. Design Style Control

Add & configure design aesthetic styles (Luxury, Premium, Modern, Minimal, Traditional, Corporate) with typography and color composition rules.

ADMIN POWER

6. User & System Management

View registered users, manage roles (`ROLE: END_USER` vs `ROLE: ADMIN`), monitor activity, and send push notifications.
